## اولین برنامهٔ تو در C++

بیا بدون معطلی اولین برنامه‌ات را ببینیم. هدف ما چاپ عبارت `Hello World!` روی صفحه نمایش است:

```cpp
#include <iostream>

using namespace std;

int main() {
    cout << "Hello World!";
    return 0;
}
```

همین چند خط ساده، کلی مفهوم مهم را در خود جای داده که در ادامه گام‌به‌گام کشفشان می‌کنیم.

## کالبدشکافی ساختار یک برنامهٔ ساده

هر برنامهٔ C++ مثل یک ساختمان از بخش‌های مشخص و استانداردی تشکیل شده. نمودار زیر یک دید کلی به تو می‌دهد:


```
┌─────────────────────────────────────────┐
│  بخش اول: دستورات پیش‌پردازنده           │
│  #include <iostream>                    │
├─────────────────────────────────────────┤
│  بخش دوم: تعاریف سراسری                 │
│  using namespace std; (اختیاری)         │
│  int globalVariable = 10;               │
├─────────────────────────────────────────┤
│  بخش سوم: تابع main()                   │
│  int main() {                           │
│      // کد اجرایی اینجا                 │
│      return 0;                          │
│  }                                      │
└─────────────────────────────────────────┘
```
حالا بیا هر بخش را دقیق‌تر بررسی کنیم.

### ۱. پایان هر دستور با سمیکالن `;`

در C++، **پایان هر دستور** با علامت **سمی‌کالن (`;`)** مشخص می‌شود، نه با رفتن به خط بعد. این قاعده‌ای است که باید از همان ابتدا ملکهٔ ذهنت شود.

```cpp
cout << "Hello";
int x = 5;
return 0;
```

> [!warning] خطای رایج: فراموشی سمیکالن
> اگر `;` را فراموش کنی، کامپایلر خطا می‌گیرد. **همیشه اول از همه وجود `;` را در انتهای دستورات چک کن.**
> ```cpp
> // ❌ اشتباه
> cout << "Hello"
> // ✅ درست
> cout << "Hello";
> ```

### ۲. پیش‌پردازنده و دستور `#include`

قبل از اینکه کدت کامپایل شود، مرحله‌ای به نام **پیش‌پردازش** اجرا می‌شود. هر خطی که با `#` شروع شود، یک دستور برای همین مرحله است.

```cpp
#include <iostream>
```

دستور `#include` محتوای فایل `iostream` را دقیقاً در همین نقطه از برنامهٔ تو کپی می‌کند. این فایل ابزارهای استاندارد ورودی/خروجی مثل `cout` و `cin` را در اختیارت می‌گذارد.

```cpp
#include <iostream>   // برای کتابخانه‌های استاندارد سیستم
#include "myfile.h"   // برای فایل‌های شخصی خودت در پوشهٔ پروژه
```

> [!info] فرق `<>` با `""`
> *   `<>` : مخصوص **کتابخانه‌های استاندارد** که همراه کامپایلر نصب شده‌اند.
> *   `""` : مخصوص **فایل‌های شخصی** که خودت نوشته‌ای و در پوشهٔ پروژه قرار دارند.

### ۳. فضای نام و `std`

تصور کن از چند کتابخانهٔ مختلف استفاده می‌کنی و هر کدام تابعی به نام `print` دارند. برای اینکه کامپایلر گیج نشود، از **فضای نام (namespace)** استفاده می‌شود. `std` نام فضای نام کتابخانهٔ استاندارد C++ است.

سه روش برای استفاده از `cout` وجود دارد که باید بشناسی:

```cpp
// روش ۱: راحت و کوتاه
using namespace std;
cout << "Hello";

// روش ۲: حرفه‌ای و شفاف (توصیه‌شده)
std::cout << "Hello";

// روش ۳: راه میانه
using std::cout;
cout << "Hello";
```

> [!tip] نکتهٔ حرفه‌ای
> در پروژه‌های بزرگ، استفاده از `using namespace std;` می‌تواند به تداخل نام‌ها منجر شود. روش استاندارد و **توصیه‌شده**، استفاده از پیشوند `std::` است.

### ۴. تابع `main`: قلب برنامه

هر برنامهٔ C++ برای اجرا به یک نقطهٔ شروع نیاز دارد. این نقطه تابعی به نام `main` است.

```cpp
int main() {
    // کدهای اجرایی اینجا نوشته می‌شوند
    return 0;
}
```

*   **`int` قبل از `main`:** نوع خروجی تابع را مشخص می‌کند. `main` باید یک عدد صحیح به سیستم‌عامل برگرداند.
    *   `0` یعنی "همه چیز درست پیش رفت."
    *   هر عدد دیگر یعنی "خطایی رخ داد."
*   **بلوک `{}`:** هر مجموعه کدی که بین `{` و `}` قرار بگیرد، یک بلوک نامیده می‌شود. بدنهٔ توابع، شرط‌ها و حلقه‌ها همگی داخل بلوک تعریف می‌شوند.

> [!danger] اشتباه رایج
> فراموش کردن `{` یا `}` باعث می‌شود برنامه اصلاً کامپایل نشود. همیشه **بلوک‌ها را متوازن نگه دار.**

### ۵. جریان خروجی و `cout`

در C++، عملیات ورودی و خروجی بر اساس مفهوم **جریان (Stream)** انجام می‌شود. داده‌ها مثل آب از یک مسیر جاری می‌شوند.

```cpp
cout << "Hello World!";
```

*   **`cout` :** مقصد خروجی استاندارد (صفحه نمایش).
*   **`<<` :** عملگر درج در جریان (Stream Insertion Operator). فلش آن جهت حرکت داده را نشان می‌دهد: از عبارت `"Hello World!"` به سمت `cout`.

### ۶. رشته‌های Literal

هر متنی که داخل `" "` (نقل‌قول دوتایی) بنویسی، یک **لیترال رشته‌ای** یا **String Literal** نام دارد. یعنی یک دادهٔ متنی ثابت و غیرقابل تغییر.

> [!warning] توجه
> اگر متن را داخل `" "` نگذاری، کامپایلر آن را یک متغیر فرض می‌کند و به خطا می‌خوری.
> ```cpp
> cout << Hello; // ❌ خطا! Hello تعریف نشده است.
> ```

### ۷. حساسیت به حروف بزرگ و کوچک

C++ یک زبان **Case Sensitive** است و بین حروف کوچک و بزرگ تفاوت قائل می‌شود.

*   `cout` ✅
*   `Cout` ❌
*   `COUT` ❌
*   `main` ✅
*   `Main` ❌

**همیشه نام‌های استاندارد را دقیقاً مطابق تعریف‌شان بنویس.**

## مهارت‌های عملی: کامنت‌گذاری و مدیریت خطا

### توضیحات در کد (Comments)

توضیحات برای خوانایی کد حیاتی‌اند و توسط کامپایلر نادیده گرفته می‌شوند.

```cpp
// این یک توضیح تک‌خطی است

/*
این یک توضیح
چندخطی است
*/
```

> [!tip] میانبر کاربردی
> برای کامنت کردن سریع یک خط کد، آن را انتخاب کن و `Ctrl + /` را بزن.

### عادت دادن خود به خطاهای کامپایلر

> [!example] تمرین طلایی
> **عمداً خطاهای زیر را در کدت ایجاد کن و پیام کامپایلر را با دقت بخوان.** این کار بهترین راه برای یادگیری و تقویت مهارت دیباگ کردن است:
> *   حذف یک `;`
> *   نوشتن `Cout` به جای `cout`
> *   حذف `" "` از دور یک رشته
> *   حذف `#include <iostream>`
> *   حذف یک `{` یا `}`
