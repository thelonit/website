## ۱. کنترل دقیق خروجی با Escape Sequences

تا حالا از `cout` برای چاپ متن ساده استفاده کردی. اما اگر بخواهی متن را در **خط بعدی** بنویسی یا یک فاصلهٔ منظم (Tab) ایجاد کنی، باید از ترکیب‌های خاصی به نام **توالی فرار (Escape Sequence)** استفاده کنی.

همهٔ این توالی‌ها با کاراکتر **`\`** (بک‌اسلش) شروع می‌شوند. این کاراکتر به کامپایلر می‌گوید: "با کاراکتر بعدی طور دیگری رفتار کن."

### جدول Escape Sequenceهای پرکاربرد

| Escape Sequence | نام | عملکرد |
| :--- | :--- | :--- |
| `\n` | Newline | مکان‌نما را به **ابتدای خط بعدی** می‌برد. |
| `\t` | Horizontal Tab | یک **تب افقی** (چند فاصله منظم) ایجاد می‌کند. |
| `\r` | Carriage Return | مکان‌نما را به **ابتدای خط فعلی** می‌برد. |
| `\a` | Alert | **هشدار صوتی** سیستم را به صدا درمی‌آورد. |
| `\\` | Backslash | از آن برای چاپ خودِ کاراکتر **`\`** استفاده می‌شود. |
| `\"` | Double Quote | برای چاپ **نقل‌قول دوتایی (`"`)** درون یک رشته. |
| `\'` | Single Quote | برای چاپ **نقل‌قول تکی (`'`)** درون یک کاراکتر. |

### مثال‌های عملی

```cpp
// چاپ در دو خط جداگانه
cout << "خط اول\nخط دوم";

// ایجاد ستون‌های مرتب
cout << "نام:\tMohammadJavad\nسن:\t20";

// چاپ یک مسیر فایل در ویندوز
cout << "مسیر نصب: C:\\Program Files\\MyApp";
```

> [!tip] نکتهٔ کاربردی
> رایج‌ترین و پراستفاده‌ترین Escape Sequence که هر روز به کارت می‌آید، **`\n`** برای رفتن به خط جدید است.

## ۲. متغیرها و انواع داده: جعبه‌های نگهداری اطلاعات

برنامه‌ها برای اینکه مفید باشند، باید بتوانند داده‌ها را به خاطر بسپارند و پردازش کنند. این کار با **متغیرها (Variables)** انجام می‌شود. یک متغیر مثل یک جعبه با یک برچسب خاص در حافظهٔ کامپیوتر است که یک نوع دادهٔ مشخص را در خود نگه می‌دارد.

> [!important] قانون طلایی
> در C++، **هر متغیر باید قبل از استفاده، تعریف (Declaration)** شود. این کار به کامپایلر می‌گوید که چه نوع داده‌ای قرار است در آن ذخیره شود و چه مقدار حافظه نیاز دارد.

### اصول نام‌گذاری حرفه‌ای متغیرها

برای اینکه کدت خوانا و قابل فهم باشد، این قوانین را برای نام‌گذاری متغیرها رعایت کن:

- **معنا‌دار باشد:** نام متغیر باید نشان دهد چه داده‌ای در آن ذخیره می‌شود (`studentScore` خوب است، `ss` بد است).
- **طول مناسب:** بهتر است کمتر از ۳۱ کاراکتر باشد.
- **بدون فاصله و کاراکترهای عجیب:** فقط از حروف، اعداد و زیرخط (`_`) استفاده کن.
- **با عدد شروع نشود:** `1stNumber` نامعتبر، `firstNumber` معتبر است.
- **CamelCase توصیه می‌شود:** برای نام‌های چندکلمه‌ای، حرف اول هر کلمه (به جز کلمهٔ اول) را بزرگ بنویس: `maxValue`, `totalAmount`.

> [!warning] C++ به حروف بزرگ و کوچک حساس است
> متغیرهای `age`، `Age` و `AGE` از نظر کامپایلر سه متغیر کاملاً متفاوت و مستقل هستند. دقت در این مورد از خطاهای رایج جلوگیری می‌کند.

### انواع داده اصلی (Built-in Data Types)

نوع داده، مشخص می‌کند که متغیر چه نوع مقداری را می‌تواند نگه دارد و چه اندازه حافظه‌ای اشغال می‌کند.

| نوع داده | کلمه کلیدی | توضیح | اندازهٔ معمول | مثال |
| :--- | :--- | :--- | :--- | :--- |
| کاراکتر | `char` | یک حرف، رقم یا نماد | ۱ بایت | `'A'`, `'9'`, `'$'` |
| عدد صحیح | `int` | اعداد بدون اعشار | ۴ بایت | `-7`, `0`, `42` |
| عدد اعشاری | `float` | اعداد با اعشار (دقت معمولی) | ۴ بایت | `3.14`, `-0.5` |
| عدد اعشاری دقیق | `double` | اعداد اعشاری با دقت بالا | ۸ بایت | `3.14159265` |
| بولین (منطقی) | `bool` | فقط دو مقدار درست یا غلط | ۱ بایت | `true`, `false` |

> [!info] نوع `string`
> برای ذخیره‌سازی متن‌های طولانی (مثل نام و آدرس)، یک نوع بسیار کاربردی و امن به نام `string` وجود دارد. این نوع جزو انواع پایه‌ای (built-in) نیست و برای استفاده از آن باید کتابخانه‌اش را اضافه کنی: `#include <string>`. در آینده مفصل با آن کار خواهیم کرد.

### روش‌های تعریف و مقداردهی اولیه

راه‌های مختلفی برای خلق یک متغیر و پر کردن آن با مقدار اولیه وجود دارد:

```cpp
// ۱. تعریف ساده (مقدار ناشناخته است)
int A;

// ۲. مقداردهی با عملگر انتساب (=)
int B = 10;

// ۳. مقداردهی با پرانتز (Constructor Initialization)
int C(10);

// ۴. مقداردهی یکنواخت با آکولاد (Uniform Initialization) - روش مدرن و توصیه‌شده
int D {10};

// ۵. انتساب مقدار جدید به یک متغیر از قبل تعریف شده
A = 20;
```

> [!tip] توصیه
> همیشه در زمان تعریف، متغیرهای خود را مقداردهی اولیه کنید. استفاده از یک متغیر تعریف‌نشده می‌تواند منجر به باگ‌های غیرقابل پیش‌بینی شود.

## ۳. دریافت ورودی از کاربر: تعامل با برنامه

برنامه‌ای که نتواند با کاربر تعامل داشته باشد، کاربرد محدودی دارد. برای دریافت اطلاعات از کاربر، از مفهوم **جریان ورودی (Input Stream)** استفاده می‌کنیم. در C++، شیء `cin` (مخفف Character Input) این کار را انجام می‌دهد.

```cpp
int age;
cout << "لطفا سن خود را وارد کنید: ";
cin >> age; // برنامه منتظر می‌ماند تا کاربر عددی را تایپ کند و Enter بزند
```

دقت کن که عملگر `>>` (عملگر استخراج از جریان) این بار برعکس `cout` عمل می‌کند و داده را **از ورودی (صفحه‌کلید) به سمت متغیر** هدایت می‌کند.

> [!note] رفتار `cin`
> `cin` با دیدن Space، Tab یا Enter خواندن یک مقدار را تمام می‌کند. پس اگر لازم است یک خط کامل (با فاصله‌ها) را بخوانی، به روش‌های دیگری نیاز خواهی داشت که بعداً یاد می‌گیری.

### زنجیره کردن ورودی و خروجی

یکی از قابلیت‌های تمیز C++ امکان زنجیره کردن (Chaining) عملگرهاست. این کار کد تو را کوتاه‌تر و خواناتر می‌کند.

```cpp
int x, y;

// زنجیره کردن خروجی: چاپ چند مقدار پشت سر هم
cout << "X = " << x << " و Y = " << y;

// زنجیره کردن ورودی: دریافت چند مقدار از کاربر
cout << "X و Y را با فاصله وارد کنید: ";
cin >> x >> y;
```

## 📌 خلاصهٔ درس

> [!success] برای مرور سریع
> - از **Escape Sequence**ها (مثل `\n` و `\t`) برای قالب‌بندی خروجی استفاده می‌شود که با `\` شروع می‌شوند.
> - **متغیر** محلی در حافظه برای ذخیره‌سازی داده است و حتماً باید قبل از استفاده **تعریف** شود.
> - **نوع داده** مشخص می‌کند که چه مقادیری می‌توان در یک متغیر ذخیره کرد (`int`, `float`, `char`, `bool`).
> - نام متغیرها باید **معنا‌دار**، بدون فاصله و با رعایت **Case Sensitivity** انتخاب شوند.
> - از **`cin`** و عملگر **`>>`** برای دریافت ورودی از کاربر استفاده می‌شود.
> - می‌توان دستورات `cout` و `cin` را برای خوانایی بیشتر **زنجیره** کرد.

> [!quote] قدم بعدی
> اکنون که با متغیرها و ورودی/خروجی مسلط شدی، آماده‌ای تا با [[3. شرط‌ها | شرط‌ها]]، برنامه‌های هوشمندتری بنویسی که بر اساس شرایط مختلف تصمیم‌گیری می‌کنند.
