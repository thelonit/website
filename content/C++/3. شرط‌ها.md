# 🧠 هوش‌مند کردن برنامه: ساختارهای شرطی در C++

تا اینجا برنامه‌های ما خطی بودند: دستورات را پشت سر هم اجرا می‌کردند، بدون هیچ تصمیم‌گیری. اما برنامه‌های واقعی باید بر اساس شرایط مختلف، مسیرهای متفاوتی را انتخاب کنند. به کمک **ساختارهای شرطی**، به کد خود "شعور" می‌بخشیم تا بتواند تصمیم‌گیری کند.

در این یادداشت، تمام ابزارهای تصمیم‌گیری در C++ را یکپارچه بررسی می‌کنیم: از `if` ساده و `else if` گرفته تا عملگر سه‌تایی و دستور قدرتمند `switch-case`.

> [!note] مفهوم کلیدی
> تمام تصمیم‌گیری‌ها در برنامه‌نویسی به یک سوال ساده ختم می‌شوند: آیا این شرط **درست (True)** است یا **غلط (False)**؟ هیچ حالت سومی وجود ندارد.

## ۱. الفبای شرط: عملگرهای مقایسه و منطق

قبل از نوشتن هر شرطی، باید بتوانی "سوال" درستی بپرسی. این سوالات توسط **عملگرهای مقایسه‌ای** و **منطقی** ساخته می‌شوند.

### عملگرهای مقایسه‌ای
این عملگرها دو مقدار را با هم مقایسه کرده و نتیجه‌ای منطقی (`true` یا `false`) برمی‌گردانند.

| عملگر | معنی | مثال | نتیجه |
| :--- | :--- | :--- | :--- |
| `==` | مساوی | `5 == 5` | `true` |
| `!=` | نامساوی | `5 != 3` | `true` |
| `>` | بزرگ‌تر | `7 > 3` | `true` |
| `<` | کوچک‌تر | `2 < 8` | `true` |
| `>=` | بزرگ‌تر یا مساوی | `5 >= 5` | `true` |
| `<=` | کوچک‌تر یا مساوی | `4 <= 5` | `true` |

### عملگرهای منطقی
این عملگرها برای ترکیب چند شرط ساده به کار می‌روند.

| عملگر | معنی | توضیح |
| :--- | :--- | :--- |
| `&&` | و (AND) | نتیجه زمانی `true` است که **هر دو** شرط برقرار باشند. |
| `\|\|` | یا (OR) | نتیجه زمانی `true` است که **حداقل یکی** از شروط برقرار باشد. |
| `!` | نقیض (NOT) | نتیجه را برعکس می‌کند (`true` را به `false` و برعکس). |

```cpp
int age = 20;
int grade = 85;

// مثال‌های ترکیبی
(age >= 18) && (grade > 80)   // true - هر دو شرط برقرارند
(age < 18) || (grade > 80)    // true - شرط دوم برقرار است
!(age < 18)                    // true - شرط داخل پرانتز false است و آن را برعکس می‌کند
```

## ۲. شرط ساده با `if` و `if-else`

### ۲.۱ ساختار `if`
ساده‌ترین شکل تصمیم‌گیری، اجرای یک بلوک کد **فقط در صورت برقراری یک شرط** است.

```cpp
if (شرط) {
    // این بلوک فقط در صورتی اجرا می‌شود که شرط true باشد
    دستور ۱;
    دستور ۲;
}
```

> [!warning] دو تلهٔ رایج و مرگبار
> ۱. **سمی‌کالن سرگردان:** هرگز بعد از پرانتز شرط، سمی‌کالن نگذار. `if (شرط);` یعنی "اگر شرط برقرار بود، هیچ کاری نکن" و دستور بعدی همیشه اجرا خواهد شد.
> ۲. **فراموشی آکولاد:** اگر از آکولاد `{}` استفاده نکنی، `if` فقط **اولین دستور بعد از خودش** را شامل می‌شود. بقیهٔ خطوط از شرط مستقل بوده و همیشه اجرا می‌شوند.

### ۲.۲ ساختار `if-else`
زمانی که برای هر دو حالتِ "برقرار بودن" و "برقرار نبودن" شرط برنامه‌ای داری، از `else` استفاده کن.

```cpp
if (شرط) {
    // مسیر الف: شرط برقرار است (true)
} else {
    // مسیر ب: شرط برقرار نیست (false)
}
```

> [!info] نکته
> `else` نمی‌تواند به تنهایی و بدون یک `if` در قبل از خودش به کار رود.

## ۳. نردبان تصمیم `if-else if-else`

وقتی بیش از دو مسیر متفاوت پیش رو داری، می‌توانی چندین شرط را پشت سر هم زنجیر کنی. **اولین شرطی که `true` شود، اجرا می‌شود و مابقی شرط‌ها حتی بررسی هم نمی‌شوند.** پس ترتیب نوشتن شروط بسیار مهم است.

```cpp
int time;
cin >> time;

if (time < 0) {
    cout << "Error! time should be positive" << endl;
} else if (time < 12) {
    cout << "Good morning!" << endl;
} else if (time < 18) {
    cout << "Good afternoon!" << endl;
} else {
    cout << "Good night!" << endl;
}
```

> [!tip] بهترین روش برای اعتبارسنجی
> همیشه شرط‌های نامعتبر (مثل ورودی منفی) را **در همان ابتدا** بررسی کن تا اگر خطایی وجود داشت، برنامه زودتر متوجه شود و باقی مسیرهای اشتباه را طی نکند. روش **صعودی** (کوچک به بزرگ) در بازه‌های عددی، معمولاً از روش نزولی منطقی‌تر است.

## ۴. شرط‌های تودرتو (Nested if) و تلهٔ `else` سرگردان

می‌توانی یک ساختار `if` را داخل `if` دیگری قرار دهی تا به تصمیم‌های لایه‌ای و پیچیده‌تر برسی. اما این کار یک تلهٔ معروف به نام **Dangling Else** دارد.

> [!danger] تله `else` سرگردان
> در کد زیر، به نظرت `else` به کدام `if` تعلق دارد؟
> ```cpp
> if (time > 0)
>     if (time < 12)
>         cout << "Wake up!";
> else
>     cout << "Time must be positive!";
> ```
> **قانون کامپایلر:** `else` همیشه به **نزدیک‌ترین `if` بدون جفت** می‌چسبد. اینجا `else` متعلق به `if (time < 12)` است، نه `if (time > 0)`. این باعث بروز خطای منطقی می‌شود.
>
> **راه حل قطعی:** همیشه با **آکولاد**، مرزها را مشخص کن.
> ```cpp
> if (time > 0) {
>     if (time < 12) {
>         cout << "Wake up!";
>     }
> } else {
>     cout << "Time must be positive!";
> }
> ```

## ۵. عملگر سه‌تایی `? :` جانشین فشرده

عملگر سه‌تایی یک روش کوتاه و یک‌خطی برای نوشتن یک شرط `if-else` ساده است. بهترین کاربرد آن برای **تخصیص مقدار به یک متغیر** بر اساس یک شرط است.

**ساختار کلی:**
```cpp
(شرط) ? مقدار_در_صورت_درستی : مقدار_در_صورت_نادرستی;
```

**مثال‌ها:**
```cpp
// تخصیص ساده
int max = (a > b) ? a : b;

// تخصیص رشته
string result = (score >= 50) ? "Pass" : "Fail";

// استفاده در خروجی (به پرانتزگذاری دقت کن!)
cout << ((grade > 90) ? "A+" : "Not A+");
```

> [!warning] محدودیت‌ها
> - هر دو شاخهٔ `?` و `:` باید پر شوند؛ نمی‌توانی یکی را خالی بگذاری.
> - برای منطق پیچیده یا اجرای چند دستور، خوانایی کد را از بین می‌برد. در این موارد، `if-else` معمولی ارجحیت دارد.
> - از سه‌تایی‌های تو در تو به شدت پرهیز کن؛ به کابوس خوانایی تبدیل می‌شوند.

## ۶. تصمیم‌گیری بر اساس مقدار دقیق: `switch-case`

وقتی لازم است بر اساس **مقادیر دقیق و مشخص یک متغیر** تصمیم‌گیری کنی، `switch` جایگزین بسیار تمیزتر و خواناتری برای زنجیره‌های طولانی `if-else if` است.

### ۶.۱ ساختار و آناتومی

```cpp
switch (expression) {
    case constant1:
        // دستورات
        break;
    case constant2:
        // دستورات
        break;
    default:
        // دستورات پیش‌فرض
}
```

| جزء | نام | توضیح |
| :--- | :--- | :--- |
| `switch (expression)` | عبارت کلیدی | متغیر یا عبارتی که بررسی می‌شود. |
| `case value:` | برچسب مورد | یک **مقدار ثابت** برای مقایسه با عبارت کلیدی. |
| `break;` | جداکننده | جلوی "سقوط" به `case` بعدی را می‌گیرد. |
| `default:` | پیش‌فرض | حکم `else` را دارد؛ اگر هیچ `case`ای مطابقت نداشت اجرا می‌شود. |

### ۶.۲ قوانین و محدودیت‌ها

> [!important] چه نوع داده‌هایی مجازند؟
> طبق استاندارد C++، عبارت درون `switch` و مقادیر `case` فقط می‌توانند از انواع **صحیح** یا **شمارشی** باشند:
>
> | نوع داده | مجاز است؟ | توضیح |
> | :--- | :---:| :--- |
> | `int` | ✅ | پراستفاده‌ترین |
> | `char` | ✅ | کاراکترها در نهایت عدد هستند |
> | `enum` | ✅ | نوع شمارشی |
> | `float` / `double` | ❌ | مقادیر اعشاری دقیق نیستند |
> | `string` | ❌ | در C++ استاندارد پشتیبانی نمی‌شود |
> | متغیر | ❌ | `case x:` وقتی `x` ثابت نباشد، خطاست |

### ۶.۳ رفتار Fall-Through (سقوط آبشاری)

مهم‌ترین نکتهٔ `switch`: **اگر `break` را فراموش کنی، اجرا به `case` بعدی "سقوط" می‌کند.**

```cpp
int day = 3;
switch (day) {
    case 1: cout << "Mon";
    case 2: cout << "Tue";
    case 3: cout << "Wed";   // اجرا از اینجا شروع می‌شود
    case 4: cout << "Thu";
    case 5: cout << "Fri";
}
// خروجی: WedThuFri
```

این ویژگی گاهی عمداً برای اشتراک‌گذاری رفتار بین چند `case` استفاده می‌شود:

```cpp
char grade = 'B';
switch (grade) {
    case 'A':
    case 'B':
    case 'C':
        cout << "Pass";      // A, B, C هر سه پاس هستند
        break;
    case 'D':
    case 'F':
        cout << "Fail";
        break;
}
```

### ۶.۴ مثال‌های عملی

**ساخت یک ماشین حساب:**
```cpp
char op;
double a, b;
cout << "Enter expression (a op b): ";
cin >> a >> op >> b;

switch (op) {
    case '+': cout << a + b; break;
    case '-': cout << a - b; break;
    case '*': cout << a * b; break;
    case '/':
        if (b != 0) cout << a / b;
        else cout << "Error! Division by zero";
        break;
    default: cout << "Invalid operator!";
}
```

**تبدیل نمره به حرف با تکنیک تقسیم:**
```cpp
int score;
cin >> score;

switch (score / 10) {   // نمره را به بازه‌های ۱۰تایی می‌برد
    case 10:
    case 9:  cout << "A"; break;
    case 8:  cout << "B"; break;
    case 7:  cout << "C"; break;
    case 6:  cout << "D"; break;
    default: cout << "F";
}
```

> [!warning] اشتباهات رایج در `switch`
> *   فراموش کردن `break` و دیدن خروجی‌های اضافه.
> *   تکرار یک مقدار ثابت در دو `case`.
> *   استفاده از `float` یا `string` در `switch` یا `case`.
> *   گذاشتن سمی‌کالن بعد از پرانتز `switch (x);`.

## ۷. مقایسه نهایی: چه زمانی از کدام ساختار استفاده کنیم؟

انتخاب بین `if`، `else if` و `switch` یک مهارت است. این جدول به تو کمک می‌کند:

| ویژگی | `if-else if` | `switch-case` |
| :--- | :--- | :--- |
| **نوع مقایسه** | هر عملگری (`<`, `>`, `!=`, ...) | فقط تساوی (`==`) |
| **نوع متغیر** | هر نوعی (`float`, `string`, ...) | فقط صحیح و کاراکتری (`int`, `char`, `enum`) |
| **مقایسه با محدوده** | بله (`x > 5 && x < 10`) | خیر (مگر با تکنیک‌های خاص) |
| **خوانایی برای موارد زیاد** | شلوغ و طولانی | بسیار تمیز و منظم |
| **سرعت (موارد زیاد)** | کندتر (بررسی تک‌تک) | سریع‌تر (پرش مستقیم) |
| **نیاز به `break`** | خیر | بله (وگرنه Fall-through) |

> [!tip] قانون سرانگشتی
> *   اگر شرط‌ها **محدوده‌ای** یا **ترکیبی** هستند: حتماً از **`if-else if`** استفاده کن.
> *   اگر صرفاً **مقادیر ثابت و مشخص** یک متغیر `int` یا `char` را چک می‌کنی: **`switch`** انتخاب خواناتری است.
> *   برای شرط‌های ساده و تک‌خطی، **عملگر سه‌تایی `?:`** بهترین دوست توست.

## 📝 تمرین‌های پیشنهادی

> [!example] تمرین ۱: ماشین حساب کامل
> برنامه‌ای بنویس که یک عبارت ریاضی ساده (عدد، عملگر، عدد) را از کاربر دریافت کند. عملگر می‌تواند `+`، `-`، `*`، `/` یا `%` باشد. با استفاده از `switch-case` عملیات مناسب را انجام بده. برای `/` حتماً چک کن که مخرج صفر نباشد و برای `%` چک کن که اعداد اعشاری نباشند.

> [!example] تمرین ۲: تحلیل کاراکتر
> یک کاراکتر از ورودی بگیر. با `switch` مشخص کن که آیا حرف بزرگ است، حرف کوچک است، رقم است، یا یک نماد دیگر. (راهنمایی: می‌توانی `case`های متوالی را برای حروف الفبا بدون `break` پشت هم بچینی تا Fall-through اتفاق بیفتد و به یک بلوک مشترک برسند).

> [!example] تمرین ۳: بازنویسی و مقایسه
> برنامهٔ تشخیص ساعت روز (صبح، ظهر، شب) را یک بار با `if-else if` و بار دیگر با تکنیک `switch (hour / 6)` بنویس. مزایا و معایب هر روش را برای خودت تحلیل کن.

## 📌 خلاصهٔ درس

> [!success] برای مرور سریع
> - سوال پرسیدن با **عملگرهای مقایسه‌ای** (`==`, `!=`, `>`, `<`, ...) و ترکیب با **منطقی** (`&&`, `||`, `!`).
> - **`if` و `if-else`:** برای یک یا دو مسیر. همیشه از **آکولاد** استفاده کن و پشت پرانتز `if` **سمی‌کالن** نگذار.
> - **`if-else if-else`:** نردبان تصمیم برای چند مسیر. ترتیب شرط‌ها مهم است و اعتبارسنجی را اول انجام بده.
> - **عملگر سه‌تایی `?:`:** روشی فشرده برای شرط‌های ساده، عالی برای مقداردهی.
> - **`switch-case`:** بهترین انتخاب وقتی صرفاً **مقادیر دقیق** یک متغیر `int` یا `char` را مقایسه می‌کنی. `break` یادت نرود، مگر در Fall-through عمدی.
> - **`else` سرگردان** را با آکولاد مهار کن.

> [!quote] قدم بعدی
> اکنون که برنامه‌ات می‌تواند تصمیم‌گیری کند، وقت آن است که بتواند کارها را بارها و بارها تکرار کند. در یادداشت بعدی، به سراغ [[4. حلقه‌ها|ساختار حلقه‌‌ها]] می‌رویم.
