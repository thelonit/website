# 🔁 تکرار بی‌وقفه: آشنایی با حلقه‌ها در C++

تا اینجا برنامه‌های ما مسیری خطی یا انشعابی داشتند: هر دستور حداکثر یک بار اجرا می‌شد. اما قدرت واقعی برنامه‌ها در توانایی انجام **تکرار** است. حلقه‌ها به ما اجازه می‌دهند یک بلوک کد را چندین بار پشت سر هم اجرا کنیم، بدون اینکه مجبور باشیم آن را بارها و بارها بنویسیم.

حلقه‌ها یکی از سه رکن اصلی برنامه‌نویسی، در کنار ترتیب و انتخاب، هستند. در این یادداشت، سه نوع حلقهٔ اصلی در C++ یعنی `while`، `do-while` و `for` را به همراه ابزارهای کنترل آنها بررسی می‌کنیم.

## ۰. پیش‌نیاز: عملگرهای افزایش، کاهش و ترکیبی

قبل از ورود به حلقه‌ها، باید با عملگرهایی که معمولاً برای تغییر شمارنده‌ها استفاده می‌شوند آشنا شوی.

### عملگرهای `++` و `--`
این عملگرها مقدار یک متغیر را **یک واحد** افزایش یا کاهش می‌دهند.

| عملگر | معادل | نام |
| :--- | :--- | :--- |
| `x++` یا `++x` | `x = x + 1` | افزایش (Increment) |
| `x--` یا `--x` | `x = x - 1` | کاهش (Decrement) |

> [!warning] تفاوت حیاتی پیشوندی (Prefix) و پسوندی (Postfix)
> تفاوت این دو فقط در لحظه‌ای مهم است که **هم مقدار را استفاده کنی و هم تغییر دهی.**
> 
> | نوع | ترتیب عملیات | مثال |
> | :--- | :--- | :--- |
> | **پسوندی** `x++` | **اول استفاده کن، بعد افزایش بده** | `y = x++;` (y مقدار قدیمی x را می‌گیرد) |
> | **پیشوندی** `++x` | **اول افزایش بده، بعد استفاده کن** | `y = ++x;` (y مقدار جدید x را می‌گیرد) |
>
> ```cpp
> int a = 10;
> cout << a++;   // خروجی: 10 (اول چاپ، بعد a=11)
> cout << a;     // خروجی: 11
> 
> int b = 10;
> cout << ++b;   // خروجی: 11 (اول b=11، بعد چاپ)
> cout << b;     // خروجی: 11
> ```

### عملگرهای ترکیبی
برای تغییرات بیشتر از یک واحد، از عملگرهای ترکیبی استفاده می‌کنیم:

```cpp
x += 5;   // معادل: x = x + 5
x -= 3;   // معادل: x = x - 3
x *= 2;   // معادل: x = x * 2
x /= 4;   // معادل: x = x / 4
```

## ۱. حلقهٔ `while` — تکرار بر اساس شرط در ابتدا

### ۱.۱ مفهوم و ساختار
`while` یعنی **"تا وقتی که"**. ساده‌ترین حلقه است: تا زمانی که یک شرط برقرار است، بلوک کد را تکرار کن.

```cpp
while (شرط) {
    // بدنهٔ حلقه
}
```

> [!note] ترتیب اجرا
> ۱. **ابتدا شرط** بررسی می‌شود.
> ۲. اگر **درست (true)** بود، بدنه اجرا شده و به مرحله ۱ برمی‌گردیم.
> ۳. اگر **غلط (false)** بود، بدنه اصلاً اجرا نمی‌شود و برنامه از حلقه خارج می‌شود.
> 
> پس `while` می‌تواند **صفر بار** هم اجرا شود.

### ۱.۲ مثال: چاپ اعداد ۱ تا ۵

```cpp
int i = 1;              // مقداردهی اولیه

while (i <= 5) {        // شرط ادامه
    cout << i << " ";   // بدنه
    i++;                // بروزرسانی شمارنده
}
cout << endl << "Tamoom shod!";
```

**خروجی:** `1 2 3 4 5 Tamoom shod!`

### ۱.۳ ردیابی گام‌به‌گام (Trace Table)

| چرخه | مقدار `i` قبل | `i <= 5`؟ | خروجی | مقدار `i` بعد |
| :---: | :---: | :---: | :--- | :---: |
| ۱ | ۱ | ✅ | `1 ` | ۲ |
| ۲ | ۲ | ✅ | `2 ` | ۳ |
| ۳ | ۳ | ✅ | `3 ` | ۴ |
| ۴ | ۴ | ✅ | `4 ` | ۵ |
| ۵ | ۵ | ✅ | `5 ` | ۶ |
| ۶ | ۶ | ❌ → خروج | — | — |

> [!warning] تله رایج: حلقهٔ بی‌نهایت
> اگر فراموش کنی شمارنده را در بدنهٔ `while` تغییر دهی (`i++`)، شرط همیشه برقرار مانده و حلقه تا ابد ادامه می‌یابد.
> ```cpp
> int i = 0;
> while (i < 5) {
>     cout << i;  // i هیچوقت تغییر نمی‌کند → حلقه بی‌نهایت
> }
> ```

## ۲. حلقهٔ `do-while` — تضمین حداقل یک بار اجرا

### ۲.۱ مفهوم و ساختار
`do-while` یعنی **"انجام بده... تا وقتی که"**. تفاوت اصلی آن با `while` این است که **ابتدا بدنه را اجرا می‌کند و سپس شرط را چک می‌کند.** این یعنی بدنه **حداقل یک بار** اجرا خواهد شد.

```cpp
do {
    // بدنهٔ حلقه
} while (شرط);   // ← به سمیکالن انتها دقت کن!
```

> [!tip] بهترین کاربرد: اعتبارسنجی ورودی
> می‌خواهیم از کاربر عددی مثبت بگیریم. باید حداقل یک بار از او سوال کنیم.
> ```cpp
> int number;
> do {
>     cout << "Yek adade mosbat vared kon: ";
>     cin >> number;
> } while (number <= 0);
> 
> cout << "Afarin! Adad: " << number;
> ```

> [!warning] نکتهٔ مهم
> برخلاف `while` و `for`، `do-while` در انتها **حتماً به یک سمی‌کالن `;` نیاز دارد.** فراموشی آن خطای کامپایلری است.

## ۳. حلقهٔ `for` — قدرتمندترین و منعطف‌ترین حلقه

### ۳.۱ مفهوم و ساختار
`for` یعنی **"برای"**. بهترین انتخاب وقتی که **تعداد تکرارها مشخص باشد.** تمام اجزای لازم برای کنترل حلقه (شمارنده، شرط و گام) را در یک خط جمع می‌کند.

```cpp
for (initialization; condition; update) {
    // بدنهٔ حلقه
}
```

| بخش | نام | چه کاری می‌کند | چند بار اجرا می‌شود |
| :--- | :--- | :--- | :--- |
| `initialization` | مقداردهی اولیه | شمارنده را تعریف و مقدار می‌دهد | **فقط یک بار**، در بدو ورود |
| `condition` | شرط ادامه | قبل از هر بار اجرای بدنه بررسی می‌شود | **قبل از هر بار** (ممکن است صفر بار) |
| `update` | بروزرسانی | شمارنده را تغییر می‌دهد | **بعد از هر بار** اجرای بدنه |

### ۳.۲ مثال: چاپ مربع اعداد ۰ تا ۱۰

```cpp
for (int i = 0; i <= 10; i++) {
    cout << i << "^2 = " << i * i << endl;
}
```

**ترتیب اجرا:** مقداردهی (یک بار) ← شرط ← بدنه ← بروزرسانی ← شرط ← بدنه ← بروزرسانی ← ... ← شرط (غلط) ← خروج.

### ۳.۳ انعطاف‌پذیری `for`: مثال‌های متنوع

```cpp
// شمارش معکوس
for (int i = 10; i >= 1; i--) {
    cout << i << " ";  // 10 9 8 ... 1
}

// گام ۲ تایی
for (int i = 0; i <= 10; i += 2) {
    cout << i << " ";  // 0 2 4 6 8 10
}

// گام ضربی
for (int i = 1; i <= 100; i *= 2) {
    cout << i << " ";  // 1 2 4 8 16 32 64
}

// چند شمارنده همزمان
for (int i = 0, j = 10; i < j; i++, j--) {
    cout << i << " - " << j << endl;
}
```

> [!warning] تله مرگبار: سمی‌کالن سرگردان
> هرگز بعد از پرانتز `for` سمی‌کالن نگذار مگر عمداً یک حلقهٔ خالی بخواهی.
> ```cpp
> for (int i = 0; i < 10; i++);  // ← حلقهٔ خالی!
>     cout << i;                 // فقط یک بار اجرا می‌شود!
> ```

## ۴. مقایسهٔ نهایی: چه زمانی از کدام حلقه استفاده کنیم؟

| ویژگی | `while` | `do-while` | `for` |
| :--- | :--- | :--- | :--- |
| **حداقل اجرا** | ۰ بار | **۱ بار** | ۰ بار |
| **زمان بررسی شرط** | در ابتدا | در انتها | در ابتدا |
| **کاربرد طلایی** | تعداد تکرار نامشخص | اعتبارسنجی ورودی/منو | تعداد تکرار مشخص |
| **مدیریت شمارنده** | دستی (خارج از ساختار) | دستی (خارج از ساختار) | درون ساختار |
| **ساختار کلی** | `while(شرط) { }` | `do { } while(شرط);` | `for( ; ; ) { }` |

> [!tip] قانون سرانگشتی انتخاب حلقه
> *   **مشخص است چند بار؟** → از **`for`** استفاده کن.
> *   **مشخص نیست چند بار، ولی حداقل یک بار باید اجرا شود؟** → از **`do-while`** استفاده کن.
> *   **مشخص نیست چند بار و ممکن است صفر بار اجرا شود؟** → از **`while`** استفاده کن.

## ۵. کنترل اجرای حلقه: `break` و `continue`

### ۵.۱ `break` — خروج اضطراری از حلقه
دستور `break` فوراً به اجرای حلقه پایان می‌دهد و برنامه به اولین خط بعد از حلقه می‌پرد.

```cpp
for (int i = 1; i <= 10; i++) {
    if (i == 5) {
        break;   // وقتی i = 5 شد، کلاً از حلقه خارج شو
    }
    cout << i << " ";
}
// خروجی: 1 2 3 4
```

### ۵.۲ `continue` — پرش به دور بعد
دستور `continue` فقط **دور فعلی** حلقه را ناتمام می‌گذارد و اجرا را به مرحلهٔ بروزرسانی (در `for`) یا بررسی شرط (در `while`) می‌برد.

```cpp
for (int i = 1; i <= 5; i++) {
    if (i == 3) {
        continue;   // دور ۳ را ادامه نده، برو به i++
    }
    cout << i << " ";
}
// خروجی: 1 2 4 5
```

> [!note] تفاوت کلیدی `break` و `continue`
> `break` یعنی **"برای همیشه تمومش کن"** و `continue` یعنی **"این دور رو بی‌خیال شو، برو دور بعدی"**.

## ۶. حلقه‌های تودرتو (Nested Loops)

### ۶.۱ مفهوم
می‌توانی یک حلقه را **داخل** حلقهٔ دیگری قرار دهی. حلقهٔ **درونی** برای هر بار اجرای حلقهٔ **بیرونی**، یک دور کامل اجرا می‌شود.

### ۶.۲ مثال: جدول ضرب
```cpp
for (int i = 1; i <= 3; i++) {      // حلقه بیرونی
    for (int j = 1; j <= 3; j++) {  // حلقه درونی
        cout << i << "x" << j << "=" << i * j << "\t";
    }
    cout << endl;
}
```

**خروجی:**
```
1x1=1   1x2=2   1x3=3
2x1=2   2x2=4   2x3=6
3x1=3   3x2=6   3x3=9
```

**ردیابی:** حلقهٔ بیرونی ۳ بار اجرا می‌شود. برای هر بار اجرای آن، حلقهٔ درونی ۳ بار اجرا می‌شود. بنابراین بدنهٔ حلقهٔ درونی مجموعاً ۳×۳ = ۹ بار اجرا می‌شود.

## 📌 خلاصهٔ درس

> [!success] برای مرور سریع
> *   **عملگرهای افزایش (`++`) و کاهش (`--`):** تفاوت پیشوندی و پسوندی فقط هنگام استفاده همزمان مهم است.
> *   **`while`:** شرط در **ابتدا** چک می‌شود. مناسب وقتی تعداد تکرار نامشخص است و ممکن است صفر بار اجرا شود.
> *   **`do-while`:** شرط در **انتها** چک می‌شود. بدنه **حداقل یک بار** اجرا می‌شود. بهترین گزینه برای منو و اعتبارسنجی ورودی. (سمیکالن آخرش یادت نرود!)
> *   **`for`:** تمام ارکان حلقه در یک خط. بهترین گزینه وقتی **تعداد تکرار مشخص** است.
> *   **`break`:** خروج کامل و فوری از حلقه.
> *   **`continue`:** رد کردن ادامهٔ دور فعلی و رفتن به دور بعدی حلقه.
> *   **حلقه‌های تودرتو:** یک حلقه درون حلقهٔ دیگر. حلقهٔ داخلی برای هر دور حلقهٔ بیرونی کامل اجرا می‌شود.

> [!quote] قدم بعدی
> اکنون با ابزارهای تصمیم‌گیری (شرط‌ها) و تکرار (حلقه‌ها) مسلح شده‌ای. گام منطقی بعدی، یادگیری [[5. آرایه‌ها|آرایه‌ها]] است تا بتوانی به جای چند متغیر پراکنده، مجموعه‌ای از داده‌ها را به صورت یکپارچه مدیریت کنی.
